# 舒适卡拉迪亚 / Calradia Comfort

当前开发版本：v0.22.7。针对《骑马与砍杀 2：霸主》v1.4.8 与《战帆》v1.2.8 编译。本版新增家族军团任务结束后自动解散：没有可行攻城且不再执行紧急救援时，走原版任务完成解散流程，成员恢复独立调度。集结、战斗及有效任务中的军团保留。设置菜单共二十五个功能开关。

v0.9.1 已公开发布至 [Steam 创意工坊：舒适卡拉迪亚 / Calradia Comfort](https://steamcommunity.com/sharedfiles/filedetails/?id=3816581137)。工坊仍为 v0.9.1，v0.22.7 尚未上传。工坊 ID 为 `3816581137`；后续版本更新同一条目。已发布版本的配置、封面与提交回执保存在 `publish` 目录。

游戏启动器中的显示名称为 **Calradia Comfort**；启动器字体无法显示中文模块名。游戏内的 Mod Options 与存档的模组列表显示 **舒适卡拉迪亚 / Calradia Comfort**。存档列表的名称通过原版显示接口映射，不改写存档内容；技术模块 ID、安装目录和 DLL 名仍为 `StorySkip`，以兼容已经使用旧版 Story Skip 的存档。

## 功能与开关

在游戏主菜单的 **Mod Options → 舒适卡拉迪亚 / Calradia Comfort** 中分别设置：

1. **跳过开局主线与战帆救援**：开局取得完整龙旗，哥哥、弟弟和妹妹进入家族。龙旗收集的六项原版前置任务会启动并按成功流程结算，包括重建家族、调查线索、初见两位导师、取得两处碎片；重建家族会获得原版的 25 声望。伊斯蒂安娜、阿尔扎戈斯的龙旗选择，以及交给国王或自立的后续任务仍由原版处理。《战帆》的奥斯蒂坎调查、与妹妹重逢和总任务会按原版成功流程结算，接受古纳尔船员的原版奖励：Wave-Steed 船及 20 名船员。中间海战章节会直接跳过，它们需要在任务启动时传送并重建玩家舰队，因此不会在任务日志中逐项记为完成。原版特维亚“村民需要帮助”潜入教学会先启动、再按成功流程结算：任务日志记下结果，获得潜行装备和 100 第纳尔，村庄上的任务标记会清除。
2. **启用 Steam 成就**：使用模组或开启作弊模式时，战役与沙盒仍可按原版成就条件获得 Steam 成就。此功能恢复成就检查，不会直接批量解锁成就。需要 Steam 成就服务正常连接，且存档没有从更高游戏版本回退。
3. **同时获得两边 Perk**：默认开启。仅主角、玩家家族成员和已加入玩家家族的同伴自动领取所有技能等级达标的两边 Perk，包括《战帆》技能的 Perk。其他家族、友军和临时入队的外人不会受影响。读旧存档、开启此功能、技能提升、加入玩家家族和角色成年时会自动补齐。原版 Perk 的一次性奖励仍按原版流程发放；开启满成长功能时，额外专精也受上限 5 限制。
4. **自动满属性、专精与技能**：默认开启。仅主角、已成年的玩家家族成员和已加入玩家家族的同伴生效。调用游戏自己的加点接口，将全部属性设为原版上限 10、每项技能专精设为原版上限 5，包括《战帆》技能；再按当前原版模型补技能经验到学习效率为 0 的实际成长极限。普通的 10 属性、5 专精对应 330，绿色区域的 240 只是学习效率开始下降的位置。读取旧存档时会修正超过上限的属性和专精，并同步修正超出实际极限的技能等级及技能经验；人物总经验、等级和已获得的 Perk 保留。普通活动不再积累技能经验，补满过程仍通过原版经验流程提升人物等级。已有和升级产生的待分配属性、专精点自动清零。关闭后恢复原版成长，已清掉的待分配点数不会补发。
5. **士兵共享经验槽**：默认开启。主角当前部队的所有普通兵种共用一个经验余额，战斗、训练等获得的士兵经验进入此余额，已有兵种经验也会迁入一次。英雄技能经验、俘虏招募进度、其他部队和驻军不参与。部队界面及升级弹窗费用区显示“共享经验”，原版升级按钮可用此余额升级任意兵种，按该分支的原版经验成本扣除；金币、马匹、物品和其他条件仍需满足。确认部队操作后结算，取消及弹窗撤销会恢复对应消耗；余额随存档保存。关闭时保留余额，新获得的经验按原版分给兵种，重新开启后恢复共享。
6. **分类一键招募**：默认开启。在原版招募页面，“全部招募”“招募普通兵”和“招募贵族兵”排列在同一行，分别将当前页面可招募的对应士兵加入待招列表。贵族兵按各国文化的贵族起点及完整升级树识别，包含帝国、阿塞莱、斯特吉亚、瓦兰迪亚、巴旦尼亚、库赛特和战帆诺德的贵族兵；费奥纳冠军所在整条兵系都包含在贵族筛选内。关系未解锁、空槽和已经选中的士兵会跳过，按原版页面顺序选取，并在金币或部队空位不足时停止。点击原版“完成”才结算金币和招募；“取消”或“重置”仍可撤销。可在已有存档中使用，关闭功能会隐藏新增按钮。

7. **一键升满建筑**：默认开启，仅玩家家族的城镇和城堡生效。在当前领地管理页面点击“一键升满建筑”，该领地全部非日常建筑立即升至原版三级，无需逐项排队，包括尚未建设的建筑。按钮点击即生效，原版“完成”按钮不负责触发升级；读档、重新开启开关、获得领地或打开管理页面都不会自动升级。逐级调用原版 LevelUp，保留建筑效果、哨所巡逻生成、总督奖励及工程经验；完成项从建设队列移除，管理页面同步刷新。住房、灌溉、庆典、练民兵等日常项目与默认选择保持原状，仍按天生效。关闭后隐藏按钮，已经完成的建筑等级保留，由原版存档保存。
8. **一键升到最高级**：默认开启，需同时开启“士兵共享经验槽”。在主角部队的士兵升级弹窗中点击新增按钮，从当前兵种可到达的最终兵种中选择一个。仅升级当前兵种栈中的普通健康士兵，不含英雄、伤兵、俘虏、其他部队或驻军。逐级检查并支付原版经验、金币、马匹、物品及 Perk 等升级条件，按能支付整条路线的人数升级；未升级者保留原兵种，不会停留在中间兵种。所选兵系的分支和最高等级由原版升级树决定。点击部队界面“完成”才最终结算，“取消”或升级弹窗撤销可还原本次升级和消耗；关闭功能会隐藏新增按钮，原版逐级升级保留。
9. **家族女性联姻改为入赘**：默认开启。玩家家族女性之后与外族男性结婚时，女方留在玩家家族，男方加入玩家家族；包括姐妹、女儿和女性主角。通过原版求婚、联姻交易或婚约确认即可生效，预览和聘金估值同步使用新的婚后家族归属。其他家族之间的婚姻、玩家家族男性娶妻、年龄、亲属及已有配偶等原版资格保持原版规则。男方若为族长，原家族须有原版认可的合格继承者；没有继承者时不允许该婚姻。有继承者时，原版会处理旧家族继承、男方部队与总督职位，并正常建立配偶关系。新加入的丈夫也受已启用的玩家家族满成长与双 Perk 功能影响。可在旧存档中使用，但不召回此前已经出嫁的女性或追溯已完成的婚姻；关闭后仅恢复之后婚姻的原版归属，已入赘的成员保留。

10. **主角多配偶**：默认开启，仅主角生效。可通过原版自愿求婚、说服及婚约流程，与多名符合资格的未婚成年角色结婚。主角可以是男性或女性；其他家族成员及外族英雄仍保持单配偶。最低年龄为 18 岁，原版近亲限制、领主资格、战争状态、对方拒绝、婚约与费用保持原版。已有配偶不会被自动离婚或变为前配偶；新配偶按原版加入主角家族，家族页面和百科显示为配偶。生育保留原版年龄、同处、概率和孕期，任一方被俘时不进行新的受孕；女性主角每天只对一位同处的自由丈夫进行原版检查，父亲在受孕时记录。子女按原版进入父母所在的玩家家族。关闭开关后停止新增多配偶，已成立的婚姻保留；主角死亡或继承时，旧主角的配偶不会变为继承人的配偶。
11. **俘虏对话当场联姻**：默认开启。与主角当前部队中的未婚成年异性贵族俘虏交谈，选择“我想与你联姻。我们商议婚约和释放条件吧。”直接打开原版交易界面，包含“联姻”和“释放对方”两项，可商议金币。预览和取消尚未提交的交易不改变俘虏、婚姻或金币。提交时先执行原版释放，随后由自由角色决定是否接受婚约：已同意婚约者可以接受；没有既有婚约时须双方关系不低于 0、原版吸引力数值不低于 40，既有拒绝仍有效。这是本模组缩短求婚的判断，不等同于完整原版说服流程。接受并确认原版婚姻实际成立后，才支付交易金币；拒绝或婚姻资格不符时不扣聘金、不结婚，已释放的角色保留自由。无需释放后重新找人，此入口也不要求先结束双方战争，不改变国家间战争状态。仍可单独选择“我会无条件释放你”。普通士兵、未成年人、近亲、已婚对象和原版不允许联姻的两位族长不包含在内。主角已有配偶时，需要同时开启主角多配偶；女性主角的新丈夫归属由入赘开关决定。

12. **丢弃物品换金币**：默认开启。普通背包中将不要的物品移到左侧“丢弃”，或在战利品页面只取走想保留的物品，点击原版“完成”后，最终丢弃的物品兑换为主角金币。默认兑换比例 30%，可在 Mod Options 中设置为 0% 至 100%。采用原版物品基础价值及品质词条倍率，不采用某座城镇的市场收购价；整批合计后舍去不足 1 第纳尔的部分。战利品只计算主角分到、最终未领取的物品，已取走和装备在身上的物品不兑换。取消不发兑换金币；正常商店出售、仓库和部队之间转移、捐赠及任务物品不参与。原版管理 Perk 带来的丢弃士兵经验仍然保留，兑换不授予贸易经验。作弊背包左侧的开窗物品目录不兑换，只计入之后实际丢入的净增加数量。成功提交的同一页面只结算一次，确认后显示金币提示；功能开关与兑换比例可在已有存档使用，无需新开档。金币使用原版存档保存，极端金额按原版整数钱包容量限制到账。

13. **百科角色实时位置与状态**：默认开启，对百科角色页面的所有英雄生效，包括尚未见过的角色。直接替换原版右侧“上次出现在……”这一行，读取当前世界数据显示正在停留的聚落、所在活动部队、城镇地牢或俘虏随行部队。地图上移动的部队显示当前最近城镇、城堡或村庄“附近”，海上部队显示附近海域；附近聚落只作定位参照，不能理解为已经进入该聚落。战斗和围攻会显示相应状态。聚落名字沿用原版百科链接。死亡、未出现、停用、逃亡、释放恢复中或旅行中而没有活动地图实体的角色会显示对应说明，不使用家乡或旧的最后出现地点填充。打开与刷新页面时立即更新，页面保持打开时每 0.5 秒读取一次；只更新当前角色页的显示，不改变认识状态、人物行踪、原版最后出现记录、下方会面/婚姻等事件日志。关闭开关后原行恢复原版文字和链接，页面布局保持原版，无需新开档。
14. **自定义家族部队数量上限**：默认开启，玩家家族作战部队总数上限默认 20，含主角部队；可在 Mod Options 中设置为 1 至 100。开启时以设置数值作为最终上限，关闭后恢复原版家族等级和统御 Perk 计算。家族部队页面与创建资格使用同一个原版模型，仍需有合格且可用的成年领队，支付创建与日常维持费用，并满足原版当前地图操作条件。此功能只改变玩家家族的上限，不生成部队、不增加同伴数量、不改变单支部队人数；商队和驻军不占用此作战部队上限。其他家族的原版限额保留。降低上限或关闭功能不会主动解散已有部队，达到或超过当前上限时不能继续新建。保存设置后重新打开家族部队页面查看，无需新开档。
15. **己方大地图固定加速**：默认开启，默认增加 1.0 点速度，可在 Mod Options 设置为 0 至 10，支持小数。在原版全部速度修正和限幅完成后增加固定数值，例如原版 3.45 变为 4.45；速度明细显示“风之气息 +1.00”。作用于玩家当前所属王国的领主部队、雇佣兵、商队、村民和巡逻等地图队伍；独立时作用于玩家家族所属队伍，主角担任雇佣兵时按雇主王国判定。陆地和海上均生效，军团整体只增加一次，附属部队保持原版跟随队形；停留、战斗等行动状态由原版控制。其他王国、敌军、中立方及盟约王国不受影响。修改开关、数值或所属阵营后，在下一次速度更新时重算，无需新开档；关闭或设为 0 后恢复原版速度。招募后的速度预估也采用此加成，但不会提前改变实际移动速度缓存。不增加存档数据类型。

16. **配偶对话立即怀孕**：默认开启。与同属玩家家族的成年配偶交谈，在主对话菜单或“很好，你有什么提议？”页面选择“我们来开一局吧。”，立即执行原版怀孕事件，跳过自然受孕的每日概率检查。男性主角使对话中的妻子怀孕；女性主角自己怀孕，并将正在对话的丈夫记录为父亲，兼容现有多配偶关系且不改主配偶。原版记录预产期并按正常孕期生育，子女进入玩家家族；双胞胎、出生性别和分娩结果由原版处理。已怀孕时选项不可重复触发；关闭此功能后隐藏选项，既有妊娠保留。仅玩家与其成年异性配偶可用，未婚成员、外族、未成年人和被俘双方不显示。战役关闭生育与死亡或缺少原版生育行为时按钮不可用，避免产生无法分娩的状态。可用于已有存档，无需新开档。

17. **主角破防、碎盾与一击破城门**：默认开启，仅战斗中的主角本人获得能力，其他家族成员、友军和敌军不获得能力。攻击敌方武器格挡、弹反和弹刀时必定突破，横斩和刺击均生效；敌方盾牌正面格挡时一击碎盾，沿用原版盾牌损毁流程，不将盾挡变成穿盾伤害。远程攻击命中敌方格挡盾牌也生效；背在身上的盾牌按原版处理。踢击、盾击等替代攻击保持原版。主角用有效武器攻击城门时，一击耗尽城门耐久，执行原版破坏事件、破坏状态和通行处理；普通场景物体、城墙及其他攻城器械不享有该能力。战斗接管的普通士兵、对话及非战斗模式不生效。关闭开关后恢复后续攻击的原版规则，不修复已破坏物品；无需新开档。

18. **攻城立即进攻**：默认开启。玩家主持围城（含主角率领军团）时，攻城营地准备立即达到 100%，可直接选择原版“率兵进攻”，无需推进时间等待。仍由玩家点击开始战斗，不自动开战；云梯和城门战斗流程保留，攻城塔、冲车及远程攻城器械仍按原版分别建造。NPC 主持、玩家只是加入的围城保持原版准备速度。已有围城中开启也可生效；完成准备后关闭开关不会倒退已经完成的营地。

19. **自定义家族同伴数量上限**：默认开启，仅玩家家族生效，上限默认 20，可在 Mod Options 设置为 1 至 100。此数值替代原版家族等级和 Perk 算出的最终同伴上限；家族页面与原版招募对话使用同一个上限。亲属、配偶与招募同伴仍按原版分类，已有同伴不会因降低上限或关闭功能被主动移除。仍需找到并正常招募同伴、支付费用，不自动生成同伴。关闭后恢复原版上限；已有存档可用，保存设置后重新打开家族页面查看。

20. **关系变化仅显示文字日志**：默认开启。原版关系增加、降低的顶部横幅、头像及提示音改为左下角文字日志，沿用原版本地化文字、变化数值和当前关系值。关系结算及原版事件照常执行；原本不显示通知、零变化和 NPC 之间的关系变化仍不提示。只调整原版关系通知接收器的输出，不拦截婚姻、俘虏、战争、同伴离队或其他重要提示，即使它们使用同一提示音也保留。关闭开关后，后续关系提示恢复原版横幅与声音。已有存档可用，无需新开档；已排入原版队列的旧横幅可能继续显示至队列结束。

21. **酒馆一键卖出家族俘虏领主**：默认开启，在城镇酒馆区菜单新增“卖出所有俘虏领主”，显示符合条件的人数及预计总赎金，点击立即出售。统一处理主角部队、玩家家族其他作战部队及家族城镇／城堡地牢中的贵族领主俘虏；可远程结算，无需手下带兵到场。仅玩家家族所属来源参与，同一王国其他家族的部队和领地不参与。普通士兵俘虏、玩家家族成员、锁定俘虏及原版限制转移的角色保留；正在交战的部队、被围攻的领地和无效俘虏记录跳过。按主角原版酒馆赎金模型计价，保留相应 Perk；使用原版转移、出售、获释、出售经验与事件流程，赎金统一进入主角钱包。领主正常结束囚禁，不转存到当前城镇地牢，防止同一俘虏重复出售。不会从敌方钱包额外扣款，计价与原版酒馆一致；通常不同于 NPC 主动提出的赎金。角色金币达到整数上限时停止出售；无需新开档，关闭功能隐藏按钮。

22. **读取存档补充便携火罐**：默认开启，新建或载入战役后，主角背包和武器栏都没有火罐时补一组，基础容量 10，手动装备。以原版普通投石为基础，沿用 Stone 分类、stone 投掷／补投动作、普通投掷物碰撞体、挂袋、自动补投和收起处理，支持步行、骑马及持盾动作。采用火罐外观、燃烧拖尾与范围伤害参数；重量 1.5、投掷速度按原版投石的 55 配置，保留此前 2300 直接伤害和 1000 火焰伤害参数。物品不再标记为任务物品，不改写战斗中的武器选择、出场或射击流程；禁售、背包丢弃与丢弃换金币通过物品专用保护处理，不进入商店货池。读档会把旧版本背包／武器栏的任务标记火罐转换为普通装备，保留原物品 ID、数量、修饰与外观数据，不重复补发，不覆盖其它装备。关闭功能停止补发，旧火罐转换与禁售保护继续生效。新增物品需保留此模组及 ModuleData 文件才能在存档中继续使用。

23. **资本利得**：默认开启，仅主角当前钱包里的金币参与，默认年化收益 15%，可在 Mod Options 调整为 0 至 100%。每经过一个游戏日，按 `(1 + 年收益率)^(1 / 游戏一年天数) - 1` 的日收益率计算复利，收益通过原版金币接口发放，显示“资本利得”文字日志。普通模式一年 84 天，加速战役一年 24 天，自动使用当前战役的实际日历。没有其他收支时，一年后金币及累计零头约为原来的 1.15 倍。花费、战利品收入等会改变之后的本金；不足一个金币的收益随存档累计。读档不立即发钱，不补算安装前、停用期间或现实离线时间的利息，同一天重复事件不会重复结算。其他英雄、城镇金库和商队资金不参与。关闭后停止后续收益，已经获得的金币保留；角色钱包达到原版整数上限时不再溢出发放。

24. **超额驻军转为村庄户数**：默认开启，仅玩家家族城镇／城堡的驻军生效。在原版每日逃兵检查前，将超过当前实际驻军人数上限的普通士兵一次退役至上限，每人转为直属村庄 1 户。先按兵阶从低到高，同阶按等级从低到高，同兵种先健康后伤兵；保留英雄，按移出人数同比扣除该兵种储存经验。户数平均分配，不能均分的余数优先给户数较少的村庄。仅直属且仍属于玩家家族的村庄接收；没有可接收村庄、正在围城或战斗、驻军停用／解散时不转换。主角野战部队、家族野战部队和外族驻军不参与。关闭后恢复后续原版流程，已增加的户数保留。只替代人数超额造成的损失，原版工资与士气逃兵仍会继续计算；左下角显示退役人数和新增总户数。
25. **家族部队优先救援与攻城**：默认开启，针对玩家家族作战部队；不接管主角、包含主角的军团、任务部队、被其他系统锁定的部队。独立部队和由玩家家族成员指挥的军团各算一个可调度单位，军团成员继续听从领队，不强行拆军团。
    - 优先保护当前己方阵营（已加入王国时为该王国）的村庄、被围城镇／城堡，以及在敌国围城时遭到敌方援军解围的友军。按原版导航路径距离给每个未覆盖事件先派最近可用队伍；计入已分配和附近已有援军，合力不足敌军估算战力的 1.1 倍时才继续补派。新威胁会在事件或下一游戏小时检查，不瞬移部队。敌方援军约进入距离围城一天行程内时启动保护；同处围城的多支敌方援军合并估算，城内守军不当作外来援军。友军围城已有足够在场战力时不额外调派。
    - 无紧急任务且未开始实际战斗／围城时，已组建且可控的军团先选择兵力、粮食足够的原版攻城候选，旧的清兵任务也可转为攻城；选定后锁定目标。攻城行军中的军团不因普通即时追敌而偏航，仍保留原版避险、附近战斗增援以及接到正式救援任务后的拦截。已有军团结束任务后，没有可行攻城且不再执行救援／围城协防时，按原版“任务完成”流程解散，不整团继续清兵、补给或巡防；成员正常脱离并恢复独立任务。正在集结、实际战斗、围城或仍有有效任务的军团不因此拆散。独立部队主动扫描附近可交战的领主、劫匪和逃兵；即使身在城内、原版没有生成追击候选，也可以选择目标出城拦截。范围取当前视野与约三小时行程较大者、最多四十地图单位，并检查原版可达路径与己方至少 1.1 倍估算战力。已分配足够拦截力量时不重复派队；目标失效、超出范围或单次任务满十二游戏小时后重评。粮食耗尽时不新发起普通追击。普通访问／巡防可以让位，正在执行的救援、战斗和已开始的围城保持优先级。救援途中不执行通用清兵：只有对应村庄的袭击者或该围城的围攻领队，位于本队近敌范围且打得过时，才改用追敌指令直接拦截；否则继续前往原救援地点。协调系统仍将其计作原救援任务。救援和围城协防的原版即时追击同样限制到对应袭击者，普通劫匪、逃兵或无关战斗不能截走队伍；原版避险仍保留。村庄停止受袭后的清理期间，只允许在该村附近拦截原袭击者，不追到远方。已调度、可达、同处陆地或海上且己方至少达到目标 1.1 倍估算战力的追击，在即时移动层直接接近目标并交给原版处理接触交战，避免原版绕行站位一直保持距离。目标失效、跨海陆或兵力不足时保留原版即时判断。
    - 取消受控手下的主动烧村评分及烧村命令。无救援任务时，从原版生成的城镇／城堡目标中选择，额外要求已到或可集结的实际战力达到守军战力乘城防优势修正后的 1.1 倍；这只是保守估算，不保证必胜。原版军团集结、临敌等待／避敌、攻城准备和强攻判定保留。军团集结候选成员排除预留队伍和已有救援／战斗／攻城任务的家族部队；已补给完成的访问队和巡防队可以参与。只在受控部队的原版军事评估期间放行家族成员组建军团，集结成员仅限本家族且排除主角，仍要求王国、战争、影响力、兵额比例、粮食和行程条件。
    - 通常新发起的攻城任务最多占可调度单位的约三分之二，向上取整预留三分之一、至少一个单位用于救援／补兵／巡防；预备队从可用独立部队中选择。已组建军团仍可承担攻城，攻城容量至少容纳当前已有军团，避免成员合并使调度单位数缩小后，反把整个军团划为预备队。兵力不足时优先执行原版给出的己方补兵补给访问；到达后完成一次约 6 小时访问再决策；同一部队结束该访问后十二小时内不重复选择同一地点补给。满足出击条件后访问／巡防任务可以转为战斗或进攻。没有合适访问目标时在家族城镇／城堡附近巡防一日，紧急救援可以提前改派。若只剩一支独立部队，默认留作救援及巡防；若已组建军团，则仍可选择可行攻城。
    - 任务目标、阶段与到达时间随存档保存；不会因其他目标得分变高、出现更近的援军队伍或读档而交换任务。已在赶路的攻城任务可以让位救村、解围及保护友军围城；已经进入围城／实际战斗的不因新事件强制撤出。仍有足够兵力与粮食的围城不随意换目标；兵力／粮食不足时允许原版撤退判断。村庄停止受袭后保留六小时清理任务，防止短暂取消烧村便让援军折返；目标易主或和平、围城结束、目标不可达等结束失效任务。围城增援针对敌方援军，援军放弃目标或远离围城后结束追击。
    - 关闭后停止后续调度与命令过滤，恢复原版战略决策；不持久禁用任何部队 AI。其他家族不会被本功能下命令，已在其他军团里的手下仍遵循该军团，不能把它们算作独立预备队。本版本尚未加载玩家存档实测行军／战役表现。

### 策略诊断与 v0.22.7 修正

启用家族部队策略后，每次进入战役会在“文档\Mount and Blade II Bannerlord\Logs\CalradiaComfort”生成 `strategy-日期-时间.log`。记录现实时间和游戏小时、村庄烧村状态变化、救援派往何处及导航距离、双方原版估算战力、原版对每支威胁部队的逃跑／攻击评分，以及最终选择的短期行动。手下每小时的任务和原版攻城候选也会记录，便于排查缺少主动攻城的原因。估算战力不是人数；普通距离字段为地图直线距离，救援 `routeDistance` 才是原版导航距离。日志不修改敌军的判断、评分或行动，也不伪装受控部队。

敌军同一行动／目标去重，每游戏小时可记录一次；变化立即记录。烧村结束后继续观察原袭击者最多十二游戏小时，以关联撤退过程。单次会话最多记录约 8 MiB，不在界面刷提示，不上传日志。关闭家族策略后停止记录；退出战役／模组卸载时关闭文件。日志仅诊断此后发生的事件，不能还原安装前未记录的 AI 决策。

v0.22.1 日志已在玩家存档中捕获烧村、救援和原版逃跑行为：援军靠近后确实存在原版逃跑，也有援军尚远时结束烧村并改去其他聚落的记录，后者原因仍待进一步原版评分记录确认。日志同时显示多支家族部队反复选择同一城市补给。v0.22.2 修正补给重选、预备队和集结资格，并保留日志；新增当前所在聚落、兵额比例、粮食可支撑天数和袭击者的原版战略评分。v0.22.2 随后出现原地等待、军团解散和闪退反馈，已由 v0.22.3 替代：长期 AI 评分现使用原版可分派的 GoAroundParty，EngageParty 仅属于即时交战层；该修正避免军团领队进入不支持行动的解散分支。巡逻数据保留目标聚落引用，走原版聚落巡逻命令，读取旧档时立即修复本功能记录的无目标聚落巡逻，避免第一帧先于下次小时调度进入《战帆》空引用。日志新增选中的具体命令及原版小时思考后的实际行动，便于核对执行结果。通过 85 项离线策略与日志检查，包括运行原版完整小时思考至最终行动端点、旧 EngageParty 导致军团解散的反例、原版《战帆》同一巡逻空引用反例及修复后调用；启动检查通过。离线导航、战力、补给、随机、模型拒绝结果与移动行动端点仍由测试边界提供，不代表完整存档实战已通过。藏身处自动清剿仍待开发，本版不包含该功能。

## 安装

将发布包内的 `StorySkip` 目录放入游戏 `Modules` 目录。更新旧版时覆盖同名目录，不要另建第二份。启动器中启用以下工作坊依赖及本模组：

- Harmony
- UIExtenderEx
- ButterLib
- Mod Configuration Menu v5
- War Sails
- Calradia Comfort

启动器应同时启用游戏自带的 Native、SandBox Core、Sandbox 和 StoryMode。开始新战役前先在主菜单的 Mod Options 中确认开局设置；游玩功能可在已有战役中调整，返回游戏后生效。

## 验证

己方加速可在旧档验证：开启且数值为 1 时，主角速度明细应出现“风之气息 +1.00”；在其他条件保持一致时，开关前后的总速度相差 1。调整至 0.5 应增加 0.5，关闭或设为 0 时该项消失。己方王国领主、商队和村民队伍应获加成，敌军与其他王国队伍不应变化；加入、退出王国后按当前阵营重新判定。军团整体不按成员数量叠加。海上原版达到 10 时，默认加成后的速度应为 11。招募预估与实际总速度应一致，取消招募不应将预估写入移动缓存；返回地图后移动与速度提示应同步。

百科实时位置可用未见过的英雄验证：打开角色页，右侧原“上次出现在……”一行应显示当前状态；被城镇俘虏时应指明地牢，被部队俘虏时应指明关押部队及其当前位置。移动部队显示附近聚落或海域，死亡/逃亡/等待恢复等状态不应显示旧地点。点击聚落名仍能打开原版百科页面。关闭此功能，原行应恢复原版历史位置文本，下方会面/婚姻等记录保持原状；认识状态与遮挡肖像不会由位置查询改变。

家族部队上限可在旧档验证：Mod Options 中确认启用且数值为 20，家族部队页面应显示相应总额度，主角部队计入。调整数值后重新打开页面应更新；达到额度时不允许继续新建。关闭后应恢复原版上限，已有队伍不会被解散。原版领队资格、金币和地图条件仍可能阻止新建，商队不计入作战部队额度。


丢弃兑换可在旧档验证：先记录金币，把一件不要的装备移到普通背包左侧，点击取消，应无兑换；重新操作并完成，应移除物品并出现“丢弃物品兑换”提示，金币增加该批基础估值的设定比例。战斗后只拿走想保留的物品，完成时剩余战利品应兑换。普通商店交易、仓库转移及捐赠不额外发金币；关闭功能后恢复原版丢弃。品质不同的同类装备应分别估值，切换比例只影响之后的兑换；保存再读档确认金币和物品结果。

入赘功能可在已有存档验证：Mod Options 中应显示“家族女性联姻改为入赘”。为本家族未婚成年女性安排与外族男性的联姻，确认提示应显示男方加入本家族；完成后夫妻双方都在玩家家族，男方不再位于原家族。男方若是族长且有合格继承者，原家族应正常更换族长；无合格继承者的族长应不能达成该婚姻。其他家族婚姻与玩家家族男性娶妻保持原版。关闭开关后，新安排的姐妹或女儿婚姻恢复原版归属；已有入赘成员保留。保存再读档后配偶和家族归属应保留。

一键建设可在已有玩家家族领地中验证：城镇或城堡管理页面应显示“一键升满建筑”。点击后当前领地全部非日常建筑应达到三级，包括未排队和零级建筑；完成项的队列清空，界面立即显示新等级，再点击原版“完成”不能恢复旧队列。日常项目选择、等级与按天收益保持原状。全部满级时按钮不可重复升级或重复发奖。读档、重新开启开关和新取得领地都不应自动升级；其他家族及同国其他领主的建筑不应变化。关闭开关后按钮隐藏，原版建设按天进行，保存再读档应保留已完成等级。

更新并重启游戏后，Mod Options 中应没有“获得所有出身与成长选项加成”。关闭“自动满属性、专精与技能”后新建战役，出身页面应只预览并发放所选项奖励，底部没有全选提示。儿童成长事件也应只获得所选项奖励。

启用剧情跳过新建“战役”，进入地图后，查看家族成员、背包龙旗、船只和任务日志。龙旗六项前置任务与《战帆》总任务应显示成功，龙旗后续选择仍可进行；队伍应有 Wave-Steed 船和 20 名船员。特维亚村庄不应再有残留的潜入任务标记，背包应获得潜行装备，金币应额外增加 100 第纳尔。已有残留标记的旧存档也可读档检查。

读取已有存档，Mod Options 中应有二十五个功能开关。开启“双 Perk”后，玩家家族所有符合技能等级的 Perk 应自动补齐；外族英雄不应改变。开启满成长功能，主角、成年家族成员和家族同伴的属性应为 10、专精应为 5，普通技能应为 330 并显示学习效率为 0，待分配点数为 0；旧版单手和双手的第 6 点应消失，370 或 410 等超额技能应修正为实际极限。关闭满成长后，新点数和普通经验恢复原版处理。儿童保持教育流程，成年后自动补满。成就需在满足对应游戏条件后，通过 Steam 的成就列表核对。
